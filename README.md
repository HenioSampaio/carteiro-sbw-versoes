# Carteiro SBW: versões

Este repositório guarda apenas as versões publicadas do Carteiro SBW (programa interno da ZAMP) e o arquivo `versao.json`, que o programa consulta para se atualizar sozinho.

O programa só funciona com uma licença emitida pelo responsável. Não há dados de clientes aqui.

Baixar a versão mais nova: https://github.com/HenioSampaio/carteiro-sbw-versoes/releases/latest/download/CarteiroSBW.exe
